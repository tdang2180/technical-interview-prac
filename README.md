# Technical Interview Prep

Hands-on refresher for full-stack engineering: writing real code by hand, not leetcode.

## Ground rules

- Write the code yourself. Turn off Cursor Tab autocomplete while practicing.
- Docs (MDN, React docs, Postgres docs) are fair game. Asking the AI for the answer is not.
- Stuck? Ask for a hint. Hints escalate: nudge, then pointed hint, then solution (only if you ask).
- When done, ask for a review. Expect follow-up "why" questions.
